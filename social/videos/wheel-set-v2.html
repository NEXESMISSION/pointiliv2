Filmed
Live screen recording (Playwright, 540x960) of the real owner page /shop/wheel on a dev server (robot shop «Café Pointili»), cut from 2.4 s, sped up 1.6×, cropped to y 170–890 (header and foot cut off). No caption overlay and no finger: the clicks are real but invisible; all text is the app's own UI.
Times
approximate (±0.2 s): live recording with waits (1200; per prize: type at 110 ms/char, 260, click «زيد كادو», 520; 500; save; 1500; switch; 2200 ms) sped up 1.6×. Anchored on changes measured in the file with ffprobe (0.54 page painted, typing 1.67–2.25 / 2.96–3.54 / 4.12–4.67, prizes added 2.46 / 3.67 / 4.96, save 5.71, saved ~8.08, switch ~10.4–11.3). The script's «قسّم بالتساوي» click never happens: adding a prize already shares the chances evenly, so that button never shows. The switch card sits at the crop's top edge, so turning it on is mostly out of frame.

The words with it in the app

The note lives in the database (news table, news.pic = this clip), not in the repo; nothing in v2 source mentions wheel-set-v2. Per commit 53ff3ec it is the note's second slide with the words «كيفاش تحضّرها» and the button to go and set it up. Exact live wording not verified.
