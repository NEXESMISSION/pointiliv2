Script

apk — «كيفاش تحطّ Pointili في تليفونك»: an explainer, not an ad. The Android app (www.pointili.online/android → public/pointili.apk) put on a phone step by step, the way a phone in French asks it: Chrome warns before the download («Télécharger quand même»), the file opens («Ouvrir»), Android asks once to let Chrome install apps («Paramètres» → «Autoriser cette source»), then «Installer» — and Pointili opens, its icon on the home screen like any app.

The phone's screens are drawn (the system's own dialogs, no logo); the app's screen in it is a real one (assets/screens). The camera moves in on each dialog, so the button to tap is big enough to read on the phone the film is watched on. No voice: the captions say it.
